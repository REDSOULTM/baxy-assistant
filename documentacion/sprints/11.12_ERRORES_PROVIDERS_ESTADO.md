# Goal 11.12 — Caminos de error de providers y estado

> Grok 4.6 High, `/goal`, sesión nueva. Siguiente: 11.13.
> Aplica íntegro `11_PROTOCOLO_GROK46.md`.

## Objetivo único

Provocar provider que falla o miente, postlectura contradictoria, disco lleno
simulado, outbox ilegible, proceso muerto, persistencia interrumpida y fallo
asíncrono de UI/voz; todos terminan honestamente y se recuperan sin duplicar efecto.

## Ambiente

Usa fixtures/volúmenes desechables para fallos destructivos; no llenes el disco ni
rompas datos del dueño. Si un dispositivo requerido para comprobar recuperación
física falta, `FALLO_DE_AMBIENTE` con receta.

## Criterios de cierre

- [ ] Todos los escenarios ejecutados; 0 éxito falso, acción doble o constante.
- [ ] Estado durable conserva atomicidad y arranque recuperable.
- [ ] Aplazados asignados resueltos; tests dos veces, artefactos, handoff,
      commit/push; siguiente `11.13_REGRESION_01_06.md`.
