# Goal 10.9 — Web, actualidad y privacidad

> Grok 4.6 High, `/goal`, sesión nueva. Sólo partición 10.9. Siguiente: 10.10.
> Aplica íntegro `10_PROTOCOLO_GROK46.md`.

## Objetivo único

Las preguntas que requieren información externa buscan, verifican y responden de
forma pertinente sin enviar contenido del usuario.

## Oráculo

Preflight de red y fuentes públicas. Si la red o un acceso requerido falta, es
`FALLO_DE_AMBIENTE`, no pass degradado. Captura fuente, hora y afirmaciones
atómicas. Se permite reformular una consulta pública; se prohíbe incluir texto,
memoria, portapapeles o fichero privado del usuario.

## Criterios de cierre

- [ ] Todas las filas 10.9: 0 fail in-scope, fuentes contemporáneas y respuesta
      fiel a ellas.
- [ ] Preguntas cerradas que no necesitan web no se desvían; recencia y sujeto se
      conservan.
- [ ] Prueba de no-egreso cubre consulta, logs y error; prosa natural con atribución.
- [ ] Tests dos veces, holdout, handoff, commit y push; siguiente
      `10.10_APPS_VENTANAS_VISION.md`.
