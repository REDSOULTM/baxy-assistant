## Objetivo único

Reconciliar todas las soluciones históricas para ejecutar peticiones simples y
compuestas sobre Windows, heredando cobertura sin recuperar capas descartadas.

## Recinto

Cubre catálogos de 67/31/16/158 operaciones, tools, skills, microagentes, UIA/OCR/
visión, adapters/providers, planes, confirmación, verificación, Steam/media,
archivos, apps, navegador, Office, comunicación, sistema y conectividad. Relaciona
cada capacidad con operación actual y prueba; una skill no sustituye autorización
del kernel ni postcondición independiente.

Busca primero implementaciones completas de misiones que Goal 10 necesitará, tanto
simples como encadenadas. Conserva patrones útiles, pero rechaza routers en serie,
listas hardcodeadas por app, respuestas fijas y éxitos no verificados. Cualquier
trasplante candidato debe decir qué capa actual elimina.
