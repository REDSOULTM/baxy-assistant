# Goal 9.5 — Recuperar todo el linaje antes del uso diario

> **Mapa: no se lanza entero.** Se ejecuta en orden mediante los ficheros
> `09.5.x`. Cada prompt se pega una vez por lanzamiento humano. `09.5.3` es una
> campaña autónoma: consume todos sus checkpoints `code_tests` bajo una sola meta
> activa. Cada ventana usa Grok 4.6 High y un máximo operativo de 500k tokens;
> una campaña persiste, compacta y continúa sin pedir que se pegue otra vez.

## Por qué se reabre la herencia

El Goal 01 no ignoró el pasado. El mapa cerrado el 2026-08-16 identificó cinco
etapas gruesas, incorporó 1.350 documentos y midió piezas de `Carter OS AI`,
`Probando Gemma 4`, `FunctionGemma` y `BAXY`. También dejó huecos explícitos:
los corpus no se inventariaron uno a uno, Carter v5 no se ejecutó, el planner
completo de FunctionGemma no pudo arrancar y la biblioteca no tiene prueba de
completitud contra las copias que hoy existen.

Además, el dueño incorporó fuentes cuya revisión exacta no estaba demostrada. Una
referencia conversacional a `Probando schemas` se aclaró después: **no existe tal
proyecto y nunca fue parte de BAXY**. La etapa Schema Agent ya está conservada en
el historial Git de `BAXY`; se audita allí, no como carpeta hermana. El Goal 9.5
concilia todo el linaje real contra la herencia cerrada, audita sus huecos/deltas y
trae las mejores piezas antes del Goal 10.

## Universo mínimo de fuentes

Las rutas son de sólo lectura y nunca son el lugar de trabajo:

- `D:\Perfil\Escritorio\ETC\Programacion\BAXY`
- `D:\Perfil\Escritorio\ETC\Programacion\Carter OS AI`
- `D:\Perfil\Escritorio\ETC\Programacion\FunctionGemma`
- `D:\Perfil\Escritorio\ETC\Programacion\Probando Gemma 4`
- cualquier carpeta adicional de `Programacion` que el manifiesto demuestre que
  es una versión real de Carter o BAXY. No se inventan fuentes por coincidencia de
  palabras como `schema`.

La etapa Schema Agent se toma de `BAXY` y de
`documentacion/25_INTEGRACION_GENERACIONAL_CARTER_SCHEMA_BAXY.md`. No requiere ni
autoriza buscar una carpeta `Probando schemas`.

`biblioteca/` y `documentacion/herencia/00_MAPA.md` son el inventario anterior
contra el que se calcula el delta; no son prueba de que la copia nueva esté
completa. `JRVS` y carpetas sin relación demostrada siguen fuera.

**Completa no significa transportar todos los blobs.** El dueño copió el material
intelectual de `Probando Gemma 4`, pero omitió deliberadamente ~140 GB de modelos,
checkpoints y datasets pesados. Eso es una fuente dispersa válida si conserva
código, documentación, pruebas, configuración, resultados y manifiestos. Los blobs
ausentes se inventarían por metadatos/evidencia histórica y sólo se pedirán si una
decisión posterior necesita ejecutar ese asset concreto.

por 09.5.1 es la autoridad: unión completa, intersecciones cero y cada unidad con
estimación conservadora menor de 300k tokens de entrada para reservar diagnóstico
y cierre. En `09.5.3` esas unidades son checkpoints recuperables de una sola meta,
no sesiones que el dueño deba lanzar.

## Frontera de idioma

El producto se compromete sólo con español, inglés y spanglish. Un corpus o una
capacidad histórica de otro idioma se inventaría, pero no se hereda como requisito
ni consume una campaña de producto. Los nombres propios y nombres ingleses de apps
—«abre Steam», «pon Spotify»— son spanglish y siguen dentro.

## Criterios agregados

- [ ] Todas las fuentes declaradas están presentes y estables; cada snapshot tiene
      procedencia, fecha, commit cuando existe Git y manifiesto de hashes.
- [ ] Ausencia de `.git` se trata como normal en proyectos locales y jamás como
      evidencia de incompletitud; SHA-256 estable identifica esos árboles.
- [ ] Toda omisión deliberada de modelos/datasets pesados tiene categoría,
      procedencia y razón; no se exige copiarla para auditar el linaje.
- [ ] Cada archivo de cada fuente tiene terminal auditable: `leido`,
      `parseado_completo`, `duplicado_por_hash`, `binario_inventariado` o
      `excluido_razonado`; cero faltantes y cero solapes.
- [ ] Cada solución, fracaso y medición relevante tiene tarjeta de evidencia con
      ruta, versión, prueba, vigencia y owner actual.
- [ ] Modelos, voz, comprensión, tools/skills, misiones simples y compuestas,
      runtime, recursos, memoria, UI y setup tienen comparación histórica.
- [ ] Cada pieza termina en `reusar`, `adaptar`, `conservar_actual`, `medir` o
      `rechazar`; ninguna preferencia sustituye evidencia contemporánea.
- [ ] Toda pieza aceptada que bloquee o acelere Goals 10–11 está trasplantada,
      probada y reemplaza —no apila— el mecanismo anterior.
- [ ] Goals 01–09 se revalidan sobre el árbol resultante y Full queda verde.
- [ ] `biblioteca`, el mapa de herencia y los prompts 10–11 reflejan el universo
      reconciliado; sólo entonces puede comenzar `10.0_BASE_VERDE.md`.
