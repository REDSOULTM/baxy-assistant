# Goal 9.5.4 — Auditar toda la campaña de evidencia y assets

> **Una sola invocación humana.** Grok 4.6 High, `/goal`, sesión nueva. Aplica
> `09.5_PROTOCOLO_GROK46.md`. Conserva terminales previos y vacía completa la
> campaña `evidence_assets`.

## Objetivo único

Extraer toda la señal verificable de corridas, corpus, modelos, checkpoints,
audio y binarios históricos sin cargar datos masivos en el contexto.

## Ejecución autónoma

Crea una sola meta activa y recorre unidades hasta `pending = 0`: claim, parser o
inventario, terminales, tarjetas, validación, cursor durable y siguiente unidad.
Una unidad o compactación no cierra el goal. Schema v1 se migra en sitio; terminales
por hash se conservan, claims vivas se reanudan y leases vencidos vuelven a
`pending`. Nunca pidas al dueño volver a pegar este fichero.

Para datos grandes crea o reutiliza parsers deterministas que procesen el archivo
entero y publiquen esquema, filas, hashes, distribución, extremos, errores y
muestras trazables. Para modelos/binarios registra hash, formato, tamaño,
procedencia, receta, consumidores y benchmark asociado; no confundas que un asset
exista con que funcione. Detecta contaminación entre train/eval, prompts vistos,
falsos positivos, hardware distinto y métricas sin denominador.

No reentrenes ni repitas campañas costosas: primero recupera sus resultados.
Ejecuta un smoke contemporáneo sólo si es seguro, acotado y necesario para resolver
si el artefacto aún arranca. Un blob pesado deliberadamente omitido se cubre con
metadatos/resultados y no bloquea. Si una decisión posterior necesita probarlo
físicamente, registra el requisito exacto para 09.5.10.

## Criterios de cierre

- [ ] Campaña `evidence_assets` completa: `pending = 0`, sin claims huérfanas y
      cada archivo con terminal válido.
- [ ] Cada archivo termina `parseado_completo`, `binario_inventariado`,
      `duplicado_por_hash` o exclusión reproducible.
- [ ] Toda métrica conserva corpus, denominador, versión, hardware y limitaciones;
      contaminación, negativos y corridas fallidas se preservan.
- [ ] Assets candidatos tienen identidad y consumidores; cero «modelo mejor» sin
      comparación equivalente.
- [ ] Parsers y reanudación probados; la campaña requirió un lanzamiento humano y
      ningún ledger apunta otra vez a este prompt.
- [ ] Ledger/tarjetas/handoff, diff, commits y push validados. Sólo entonces sigue
      `09.5.5_MODELOS_ROUTER_IDIOMAS.md`.
