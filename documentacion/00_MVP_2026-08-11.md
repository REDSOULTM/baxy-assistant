# MVP ejecutable de BAXY — 2026-08-11

## Resultado

Este adelanto abre el producto integrado existente: interfaz WPF/WebView2,
Core verificado y mente local. No reconstruye BAXY, no entrena modelos, no
modifica la instalación activa y no promueve activos experimentales.

Desde la raíz canónica del repositorio:

```powershell
.\run_mvp.ps1
```

Opciones útiles:

```powershell
.\run_mvp.ps1 -NoWake       # abre la app sin escuchar automáticamente
.\run_mvp.ps1 -Cpu          # ejecuta el LLM sin capas GPU
.\run_mvp.ps1 -ValidateOnly # comprueba todo sin abrir la app
```

## Qué combina

- La mejor wake word ya medida: cascada endpoint v25a. El lanzador exige su
  SHA-256 exacto y el SHA-256 de su evidencia antes de abrir BAXY.
- Nemotron Streaming produce únicamente transcripciones parciales para reducir
  el silencio percibido.
- Parakeet TDT int8 produce la transcripción final y sigue siendo la autoridad.
- Qwen3-4B Q4_K_M y llama.cpp usan la configuración GPU local registrada.
- La voz de salida usa la degradación local SAPI mientras no exista una voz
  neural registrada.
- El catálogo, confirmaciones, verificadores, journal y replay siguen siendo
  los del producto real; el lanzador no les agrega autoridad.

No se adoptó el experimento de hotwords contextuales como reconocedor final:
su corrida válida empeoró exactitud y latencia. La matriz posterior fue
interrumpida deliberadamente para entregar este MVP y no cuenta como evidencia.

La v25a es la mejor candidata disponible, pero continúa marcada como
`developmentOnly`: falta una prueba física ciega fresca con el usuario
despierto. Por eso `run_mvp.ps1` permite usarla únicamente si coinciden ambos
hashes y muestra una advertencia. No se registra ni se presenta como promovida.

El MVP tampoco demuestra aún el 99 % global de la meta. Entrega una aplicación
normal y comprobable mientras continúa la certificación integral.
