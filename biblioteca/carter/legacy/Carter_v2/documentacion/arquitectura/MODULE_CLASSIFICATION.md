# Module Classification — Carter v2

> Generated by F-CLASSIFY / F-VISION (radical/text-closure).
> Goal: make startup cost honest and let the audit team see, at a glance,
> which subsystems are truly needed for a text-only turn vs which are
> opt-in.

Each module is placed in **one** of four buckets:

| Bucket | Meaning |
|--------|---------|
| **CORE** | Required to serve any turn. Eager import is acceptable. |
| **KEEP_LAZY** | Heavy or environment-dependent. Must be imported on first use, never at startup. |
| **OFF_BY_DEFAULT** | Available but gated by env-flag, config file, or external prereq (Steam, HEARTBEAT.md…). |
| **DELETE** | Dead code, no import sites, or superseded. None at present. |

## CORE

### `carter_v2/universal/**` (all 13 modules)
- `checkpoint.py`, `computer_use.py`, `context.py`, `memory_policy.py`, `memory_store.py`, `plan_graph.py`, `resource_resolver.py`, `runner.py`, `runner_types.py`, `task_frame.py`, `task_frame_builder.py`, `tool_index.py`.
- All eagerly imported through the universal-agent execution context. No heavy I/O at import time; safe to keep eager.

### `carter_v2/capabilities/**` core set
- `base.py`, `registry.py`, `probe.py`, `app_resolver.py`, `_subprocess.py`.
- Standard tool capabilities: clock, code, database, filesystem, memory, network, terminal, process, system, etc.
- Vision/GUI helpers that are pure-Python and side-effect-free at import time:
  - `vision.py` — `VisionCapability`. Eager class definition; the heavy work happens through the (lazy) router on `execute()`.
  - `_vision_suggestions.py` — pure helpers.
  - `_dialogs.py` — already imports `vision_router` lazily (line 348).
  - `_gui_planner.py`, `screen_cache.py`, `input.py`, `ui.py`, `window.py`.

|--------|----------|
| [capabilities/vision_router.py](src/carter_v2/capabilities/vision_router.py) | LLM-vision / OmniParser / pytesseract probes are expensive and env-dependent. Must only run when a `vision_*` or `gui_*` tool actually executes. |
| [capabilities/_graceful_close.py](src/carter_v2/capabilities/_graceful_close.py) (F-A1) | Imports `pywin32` / WM_CLOSE machinery only when a process_stop_app actually runs. |
| [capabilities/_env_persist.py](src/carter_v2/capabilities/_env_persist.py) (F-A2) | Touches HKCU registry; only loaded when an env tool is invoked. |
