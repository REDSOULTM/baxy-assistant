# Carter v3 Documentation

Documentacion unificada de Carter v3.

## Estructura

- `analysis/`: analisis globales y gap analysis.
- `architecture/`: mapas y documentos de arquitectura.
- `audit/`: auditorias, prompts y validaciones formales.
- `competition/`: auditorias comparativas, matrices y notas de competidores.
- `history/`: reportes historicos, ciclos y bitacoras de cierre.
- `planning/`: roadmaps, planes tecnicos e ideas a portar.
- `prompts/`: prompts operativos de trabajo y validacion.
- `roadmap/`: roadmap interno de rondas e implementacion.

Se mantienen en la raiz del workspace:
