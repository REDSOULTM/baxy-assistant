## CLUSTERS POR CAUSA RAÍZ

### 🔴 FIX AHORA #1 — Idioma: el reply NO espeja el idioma del usuario (PATRÓN NUEVO, universal)
- **Tamaño real medido: 1072 de 1290 casos no-ES (83%)** responden en español. El juez solo etiquetó ~110; es 10× más grande de lo que parece.
- **Causa raíz (encontrada):** `gemma4_agent/prompts/core.md:7` hardcodea `"Speak Spanish to the user by default."` y NO hay ninguna instrucción de espejar el idioma. El **dataset gold espeja el idioma nativo en el 86% de los casos no-ES** ("Opening Notepad", "Il est HH:MM", "Apro la calcolatrice") → el comportamiento deseado es claro y el runtime lo incumple.
- **Eje:** idioma. **Sev:** media individual, pero **es el defecto sistémico #1 de las tandas** y viola directamente el principio de universalidad (CLAUDE.md: multi-idioma).
- **Fix:** una línea de prompt — reemplazar "Speak Spanish by default" por "Reply in the SAME language as the user's latest message; default Spanish only if ambiguous." Estructural, sin hardcode de contenido ni keywords. **Probar EN VIVO** con en/pt/fr/de/it antes de cerrar (el 4B es no-determinista; verificar que no rompa el routing ni el ES).

### 🔴 FIX AHORA #2 — Destructivo/irreversible se ejecuta sin confirmación real (HUECO real de un fix existente)
