accessibility(...) = Windows Ease of Access features. Actions: status, magnifier_start, magnifier_stop, narrator_start, narrator_stop, dictation_status, settings_panel.

NOT FOR: system audio output/volume (use audio(...)); brightness or display scaling (use system(action='brightness_*') or device_settings).

High Contrast toggle intentionally deferred. settings_panel opens the OS settings page for the user to change anything not exposed here.
