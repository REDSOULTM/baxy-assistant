backup_sync(...): crea/restaura backups ZIP locales. Actions: status, backup_create, list, restore, dedupe, verify.
Mantiene índice. restore: overwrite|skip|rename. Halla duplicados por SHA256. verify: integridad del ZIP.
!= filesystem archive|unarchive (zip one-off); != cloud sync.
USAR: snapshot recuperable de carpeta, o deduplicar árbol. NO para replicación off-machine.
