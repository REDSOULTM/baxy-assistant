Source-manager rule: source_manager(...) is a local citation / source store. Actions: status, save, add, list, sources, search, read, get, delete, snapshot_file.

Stores titles, URLs, snippets and file snapshots in local state for later citation. snapshot_file freezes a copy of a file at a point in time.

Distinct from memory(...) (key-value, not source-aware), from notes_tasks(...) (free-form), and from web(...) (does not persist results). Use source_manager when the user wants to keep evidence around for later reference.
