memory(...): persistent across sessions/restarts. Actions: save|recall|list|delete.
SAVE ONLY when user explicitly asks to remember/store — spontaneous saves clutter store + pollute later recalls.
NOT notes_tasks(...) (free-form structured notes) nor history compaction (per-conversation). memory survives restarts.
recall -> cite the EXACT stored value, don't paraphrase (user wrote it that way for a reason).
