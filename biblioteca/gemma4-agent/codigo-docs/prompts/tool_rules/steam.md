Steam rule: for installed Steam games use steam(action="launch_game", query="<game>"). If the user says "abre Steam y ve a mi biblioteca", use steam(action="library"), not steam(action="open"). If the user says "busca X en mi biblioteca de Steam", use steam(action="search_library", query="X"). If the user asks for the Steam store page of a game/app, use steam(action="store_page", query="X") or steam(action="search_store", query="X"). Do not open a normal web browser for Steam store tasks unless the user asks for the web browser specifically. Do not split "ponme en la pagina de la tienda de X" into store then ask; open the target page in the Steam client directly when possible.
