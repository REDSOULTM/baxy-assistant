Memory rule: memory(...) is persistent across sessions. Actions: save, recall, list, delete.

SAVE ONLY when the user explicitly asks to remember / store something. Spontaneous saves clutter the store and pollute later recalls.

Distinct from notes_tasks(...) (free-form notes with structure) and from history compaction (per-conversation). memory survives across restarts.

When recalling, cite the exact stored value rather than paraphrasing — the user wrote it that way for a reason.
