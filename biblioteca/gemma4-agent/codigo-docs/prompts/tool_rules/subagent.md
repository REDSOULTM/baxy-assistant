Subagent rule: use subagent(action="run", task="<focused instruction>", max_turns=4) only when the parent task has a clearly bounded sub-task that benefits from a fresh, smaller context (e.g. "scan my Steam library and return only games tagged metroidvania"). The child agent starts with empty history and only the tools you pass in `tools=[...]` (subset). Do NOT use subagent for the main user request; that's the parent's job. Do not chain subagents recursively unless the user explicitly asks.
