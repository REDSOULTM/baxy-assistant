Smart home rule: local Home Assistant control uses smart_home(...). Requires GEMMA4_HASS_TOKEN env var (long-lived access token from your HA profile); set GEMMA4_HASS_HOST if HA is not at homeassistant.local:8123. If status returns has_token=false, tell the user how to create the token. Use call_service(domain, service, data) for the heavy lifting; scene_run and area_control are shortcuts. For MQTT-only setups, use mqtt_publish (needs paho-mqtt installed).
