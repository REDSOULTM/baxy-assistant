# FILES1040 — buscar nombres y abrir una carpeta conocida

Primera tanda de este mecanismo: tres literales exactos H0001/H0696/H0711,
diez variantes originales y cinco límites. No se rellenan diez literales con
operaciones confinadas al sandbox que no cumplen destinos del usuario.

H0001/H0696 piden búsquedas por nombre. Se ejecuta filesystem.known.search sobre
las carpetas reales admitidas y se compara cada respuesta con resultados y ámbito
observados. Una ausencia sólo pasa si fue buscada realmente y la respuesta acota
dónde no hubo coincidencias; no significa buscar todo el disco. No inventar rutas,
unicidad ni archivos. No crear archivos para conseguir una coincidencia de encuesta.

H0711 requiere abrir Descargas real mediante filesystem.folder.open y verificar
la ventana. Las variantes de apertura nombran otras carpetas reales soportadas;
no se acredita foco si sólo consta ventana visible. No escribir, borrar ni mover
archivos, ni completar contenido truncado de la encuesta.

Seis variantes de búsqueda y cuatro de apertura, con nombres/ubicaciones/idiomas
distintos. Cada literal requiere dos variantes pertinentes pasadas en esta tanda o
en una previa comprobada. Los cinco límites prueban prohibiciones, citas y preguntas
sin autorizar el efecto mencionado; nunca acreditan encuesta. Máximo tres créditos,
adjudicados contra los hechos observados, no contra el exit del conductor.

Cada caso se precede de session.new. Material, mapa, snapshot y transporte sellados
antes de candidato/ejecución. No se reutiliza el endpoint CDP de WEB1039 para esta
tanda. Se heredan guardas4000 MiB libres al inicio,768 mínimo,3800 GPU atribuible,
900 segundos y120000ms por turno. Root mantiene sólo una instancia del producto,
cierra sólo su árbol por identidad y conserva journal y efectos inciertos.

Pruebas automatizadas, Fast y Full omitidos por instrucción del dueño. Se reutiliza
el build1036 únicamente con huella y binarios coincidentes. No se afirma una suite
verde. La evidencia de búsqueda se conserva privada; el informe público evita rutas
o contenido personal ajeno a lo necesario para comprobar el veredicto.
