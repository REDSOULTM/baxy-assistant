# C03 — R07 inyección declarada en compose

Variable: `BAXY_COMPOSITION_INJECTION` (`reject` | `timeout` | `exhaust`).
La petición entra por el conductor C01. La inyección se declara en
`oracle-after.txt` y en el evento `composition_failed.injected`.

| Corrida | Inyección | Terminal | Causa pública | Controles |
|---|---|---|---|---|
| r07-reject | reject | composition_failed | unsafe_language;retry_exhausted | isInputEnabled true |
| r07-timeout | timeout | composition_failed | composer_request_failed;retry_exhausted | isInputEnabled true |
| r07-exhaust | exhaust | composition_failed | no_response;retry_exhausted | isInputEnabled true |
| r07-real | ninguna | published_final | «La hora local es 17:27.» | isInputEnabled true |

No hay silencio ni `accepted` como éxito. No hay literal de disculpa: el estado
es `composition_failed` + activity SYSTEM. Tras restaurar el recurso (corrida
real) la hora vuelve a publicarse.
