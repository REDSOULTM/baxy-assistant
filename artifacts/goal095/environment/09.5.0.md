## Prueba de readiness (antes de relanzar)

En PowerShell, desde cualquier sitio. Tiene que salir `READY=1` y nada en rojo.

```powershell
$root = 'D:\Perfil\Escritorio\ETC\Programacion'
$need = @(
  'BAXY',
  'Carter OS AI',
  'FunctionGemma',
  'Probando Gemma 4',
  'Probando schemas'
)
$need | ForEach-Object {
  if (-not (Test-Path -LiteralPath (Join-Path $root $_))) { "MISSING $_" }
}
$models = Join-Path $root 'Probando Gemma 4\models'
$data = Join-Path $root 'Probando Gemma 4\data'
$modelsFiles = @(Get-ChildItem -LiteralPath $models -Force -Recurse -File -ErrorAction SilentlyContinue).Count
$dataBytes = [int64](Get-ChildItem -LiteralPath $data -Force -Recurse -File -ErrorAction SilentlyContinue | Measure-Object Length -Sum).Sum
"models_files=$modelsFiles (gate: >0; esperado del mapa 01: arbol de ~17GiB)"
"data_bytes=$dataBytes (gate: >= 30000000000; mapa 01 ~39GiB)"
$schemaHits = Get-ChildItem -LiteralPath $root -Force -Directory | Where-Object {
  $_.Name -match '(?i)schema'
}
"schema_dirs=$($schemaHits.Name -join ' | ')"
$copy = Get-CimInstance Win32_Process | Where-Object {
  $_.Name -match 'robocopy|xcopy|FastCopy|TeraCopy'
}
"copy_procs=$($copy.Count) (gate: 0)"
$pg4 = Join-Path $root 'Probando Gemma 4'
$n1 = @(cmd /c "dir /s /a-d `"$pg4`" 2>nul" | Select-Object -Last 1)
Start-Sleep -Seconds 30
$n2 = @(cmd /c "dir /s /a-d `"$pg4`" 2>nul" | Select-Object -Last 1)
"pg4_dir_footer_1=$n1"
"pg4_dir_footer_2=$n2  (tienen que coincidir)"
$ready = (
  (Test-Path -LiteralPath (Join-Path $root 'Probando schemas')) -and
  ($modelsFiles -gt 0) -and
  ($dataBytes -ge 30000000000) -and
  ($copy.Count -eq 0) -and
  ($schemaHits.Count -ge 1)
)
"READY=$([int]$ready)"
```

Gates:

- Las cinco rutas mínimas existen y se pueden listar.
- Al menos una carpeta de primer nivel cuyo nombre coincida con `(?i)schema`
  (será `Probando schemas` y/o Agent/Function Schema).
- `Probando Gemma 4\models` tiene ficheros; `data` ≥ 30 GiB (el mapa 01 hablaba
  de ~39 GiB; 30 GiB es el suelo para no relanzar sobre el recorte de 247 MiB).
- Cero copiadores vivos y el `dir /s` de `Probando Gemma 4` no crece en 30 s.

Si Agent/Function Schema es un árbol **aparte** de `Probando schemas`, tiene que
aparecer también en `schema_dirs`. Si tras copiar `Probando schemas` el dueño
sigue sin poder señalar Agent/Function Schema en `Programacion`, 09.5.0
volverá a fallar: esa ausencia está escrita en el prompt.
