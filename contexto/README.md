# Contexto operativo de BAXY 1.0

Esta carpeta es la memoria versionada de la reconstrucción. Permite reanudar el
trabajo sin reconstruir decisiones, pero no sustituye Git, pruebas ni evidencia
física.

## Reanudación

Leer, en este orden:

1. `00_control/MAPA.md`;
2. `00_control/ESTADO_ACTUAL.md`;
3. `00_control/ALCANCE_Y_DEFINITION_OF_DONE.md`;
4. únicamente los archivos canónicos de la fase activa.

## Reglas

- Registrar fecha, procedencia, confianza, impacto y destino de cada hallazgo.
- Enlazar evidencia; no copiar logs, binarios ni sesiones privadas.
- No guardar secretos ni datos privados innecesarios.
- Marcar decisiones sustituidas; no borrar contradicciones.
- Actualizar `ESTADO_ACTUAL.md` después de hitos, fallos, benchmarks, commits y
  cambios de fase, y antes de cualquier proceso largo.
